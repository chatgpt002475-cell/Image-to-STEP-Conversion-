ImageCAD - SolidWorks Style Web CAD Studio

A high-performance in-browser 3D CAD application that converts images into real 3D solids with SolidWorks-layout CommandManager, FeatureManager tree, PropertyManager, and ISO 10303-21 STEP AP214 export.
